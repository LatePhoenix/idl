## Deviations and choices

1. Derivation still triggers only when the matching **primary is overridden** (same as the old mix). Authored asset shadow/highlight stay until the user picks a primary — so default contact sheets and widget goldens did not need re-recording.
2. Pack `defaults` for identity still come from the first pack (`core_proto`); `slotLinks` and `palettes` **merge** across packs so `emoji_core` can own the AP-9 data.
3. Skin mid/deep tones often fail WCAG 3:1 against the teardrop outline (`#7A4E00`); the pack test requires outline **or** light-scene contrast.
4. Brows in `emoji_core` already paint with `hair.primary`; the `brow.primary` → `hair.primary` link is for future brow slots. `beard.primary` is the live link.

## Known limitations

- Editor UI for swatches / unlink / warnings is AP-11.
- Studio preview still skips procedural layers and wallpaper outline contrast (unchanged).
