## What was implemented

`python tools/import_art.py retire <old> --to <new>` records a retirement and removes the old id from the shipped asset list.

| Criterion | Result |
| --- | --- |
| Writes the `retired` mapping | met |
| Refuses a removal with no replacement | met — missing `--to` is a usage error; an unknown replacement is refused |
| Refuses a second, different replacement | met |
| Does not edit the real pack from the tests | met |
| Saved avatars still resolve through `AssetRegistry.canonicalId` | met — existing domain test; this command writes the same map |

Promote is the importer (D-51), so there is no separate promote command and no beanie demonstration PR.

## Deviations

- The command lives on `import_art.py` with the other pack edits. It rewrites the catalog the same way import does.
- The SVG and picture files stay on disk. The id leaves the manifest, and the mapping keeps saved avatars working.

## Known limitations

- Retiring an id does not add a SQL migration. F-39 still means a catalog seed change does not update an already-migrated database.
- The command does not check that the replacement is the same category.
