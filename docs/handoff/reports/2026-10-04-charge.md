## What landed

- `ChargeEngine` (`domain/Charge.kt`) is pure Kotlin. Callers pass `nowEpochMs`. Whole Charge only; leftover milliseconds stay on `lastEvaluatedEpochMs`. A zero rate, or a gap longer than 24 hours, moves the timestamp to now so that time is not paid later. The ceiling limits one evaluation, not the balance. The current tether count applies to the whole gap.
- `EconomyRepository` commits that result, exposes `StateFlow<ChargeState>`, and is evaluated from reconcile, widget refresh, and the Status Deck.
- Room database version 2 adds `user_economy` and `friend_tethers`. `isMutuallyTethered` is computed (`local && remote`), not a column. `tetherActivatedEpochMs` is set when a tether becomes mutual and cleared when it breaks.
- Pinning a friend widget sets `hasLocalWidgetInstalled`. Deleting the last widget for that friend clears it.
- `AvatarBadges.resonating` draws a small corner dot. It is not derived from mood.
- Debug settings (fake backend only): “Their widget is on my home screen”, “Friend has your widget installed”, and “Accrue 1 hour”.

## Deviations

- `isMutuallyTethered` is a getter. Storing it would drift from the two flags.
- `hasRemoteWidgetInstalled` is a local column. Nothing on the server reports the friend’s widget yet, so demo settings write it. A later sync can call `setRemoteWidgetInstalled`. No Supabase migration was added.
- The 24-hour ceiling is the uncollected window. `currentCharge` is not capped.
- Debug settings also toggle the local pin and offer “Accrue 1 hour”, so one device can see a balance change without waiting and without a system widget.
- Reconciling widget subscriptions sets local pins from real widgets only, which clears a demo-only local flag.

## Limitations

- Charge lives in Room on this device. It does not follow the account to another device.
- Spending Charge in the Avatar Lab is not implemented.
- There is no instrumented test of the Room migration. The v2 `createSql` matches `MIGRATION_1_2`.
